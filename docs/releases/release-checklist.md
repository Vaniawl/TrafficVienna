# Release Checklist

TrafficVienna's maintained release evidence is in `docs/release/app-store-readiness.md` and
`docs/release/testflight-smoke-checklist.md`, with current command evidence in `CHECKS.md`
and `STATUS.md`. Framework release reviews must use those sources and their limitations.

Agent-framework adoption is tooling-only. No release, deployment, signing, submission, or
external publication is authorized by this document.
